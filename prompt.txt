Project Summary for AI Interview Context:

This project is a full-stack AI-powered task management system with a Node.js/Express/MongoDB backend and a React/Vite/Tailwind CSS frontend. The following is a summary of the work performed, including UI/UX enhancements, bug fixes, and configuration changes.

**1. Layout and Navigation Enhancements:**
*   **Sticky Navbar and SideMenu:**
    *   Ensured the `Navbar` (frontend/src/components/layouts/Navbar.jsx) remains sticky at the top of the viewport.
    *   Updated the `SideMenu` (frontend/src/components/layouts/SideMenu.jsx) to also be sticky at the top by adding `top-0` to its main div's class.
*   **Settings Screen Integration:**
    *   Initially attempted to wrap `PrivateRoute` with `DashboardLayout` in `App.jsx`, which was later reverted.
    *   The correct approach was implemented by modifying `App.jsx` to directly wrap the `UserSettings` component with `DashboardLayout` in its respective admin and user routes. `DashboardLayout` was also imported into `App.jsx`.

**2. Navbar Functionality and Styling:**
*   **Moved Action Buttons to Navbar:**
    *   The "message button", "new task button", and a "my task only selection button" were moved from their original locations (Admin/Dashboard.jsx, User/UserDashboard.jsx, and ManageTasks.jsx) to the `Navbar` (frontend/src/components/layouts/Navbar.jsx).
    *   Original locations were replaced with "fizap" placeholders.
    *   **Navbar Changes:**
        *   Imported `useContext` from React.
        *   Imported `useNavigate` from `react-router-dom`.
        *   Imported `UserContext`.
        *   Added `sendMessage` function for navigation to messages.
        *   Added `createTask` function for navigation to task creation (conditional based on user role).
        *   Added `handleMyTasksOnly` function for navigation to filtered task lists.
        *   Imported `LuMessageCircle`, `LuCirclePlus`, `LuListTodo` icons.
        *   Added corresponding `Button` components for these actions to the Navbar.
*   **Navbar CSS Refinements:**
    *   Increased the gap between action buttons in `Navbar.jsx` from `gap-2` to `gap-4`.
    *   Added `shadow-md` to the main Navbar div for better visual depth.
    *   Converted the "My Tasks" button to an icon button (`LuListTodo`) and applied `p-2` padding to all icon buttons for consistent sizing and clickable areas.

**3. Scrolling and Layout Fixes (Messages Screen & General):**
*   **Global Scrolling Control:**
    *   Added `height: 100%;` and `overflow: hidden;` to `html` and `body` tags in `frontend/src/index.css` to prevent the entire window from scrolling.
    *   Removed `overflow-y-auto` from the content area `div` in `DashboardLayout.jsx` to prevent the entire dashboard from scrolling.
    *   Later, `overflow-y-auto` was added *back* to the content area `div` in `DashboardLayout.jsx` to make the main content scrollable, as the previous change made screens unscrollable.
*   **Messages Screen Specific Fixes:**
    *   **Padding Issue:** Removed `pb-16` from `DashboardLayout.jsx` (which was causing excessive bottom padding on the message screen).
    *   **Conditional Bottom Padding:** Implemented conditional `pb-16` in `DashboardLayout.jsx` to apply bottom padding only to screens *other than* the "Messages" screen, allowing other content to be fully visible while scrolling without affecting the message screen's layout.
    *   **Conversation List Width:** Increased the width of `ConversationList` (frontend/src/components/messages/ConversationList.jsx) from `w-1/4` to `w-1/3` to provide more space for usernames.
    *   **Chat Window Username Visibility:**
        *   Added `truncate` class to the `h2` tag displaying the username in `ChatWindow.jsx` (frontend/src/components/messages/ChatWindow.jsx) to handle long names.
        *   Added `console.log` statements in `ChatWindow.jsx` to debug username data flow (output still pending from user).
        *   Removed temporary `bg-black` and reverted to `bg-gray-50` on the main `div` of `ChatWindow.jsx`.
        *   Added `h-0` to the `div` with `messagesEndRef` in `ChatWindow.jsx` to prevent it from taking up space and potentially interfering with scrolling.
    *   **Messages Component Height:** Added `h-full` to the `div` wrapping `ConversationList` and `ChatWindow` in `Messages.jsx` (frontend/src/pages/Messages.jsx) to reinforce height constraints.

**4. User Settings UI/UX Improvements:**
*   **Standardized Input Styling:** Applied the `input-field` class to all `<select>` elements in the "Preferences" tab of `UserSettings.jsx` (frontend/src/pages/Settings/UserSettings.jsx) for consistent visual styling.
*   **Improved Visual Grouping:**
    *   Added `mb-6` to the main form/div elements within each tab (`profile`, `security`, `notifications`, `preferences`, `privacy`) in `UserSettings.jsx` for better vertical spacing.
    *   Added visual separators (`border-t border-gray-200 pt-4 mt-4`) between logical groups of settings within the "Notifications" and "Preferences" tabs for enhanced readability and organization.

**5. Undo Operations:**
*   An attempt was made to undo changes in `User/UserDashboard.jsx` related to moving buttons and the `potentialOverdue` block. This was partially successful due to previous modifications and user cancellation. The final state of `User/UserDashboard.jsx` after the undo was:
    *   `potentialOverdue` block in its original position and styling.
    *   "My tasks only" checkbox replaced with "fizap".
    *   Message button and new task button restored.

**6. Project Management Features (Phase 2 & 3 Implementation):**
*   **Backend API Endpoints:**
    *   **Project CRUD:** Implemented `POST /api/projects`, `GET /api/projects`, `GET /api/projects/:id`, `PUT /api/projects/:id`, `DELETE /api/projects/:id` in `backend/controller/projectController.js` and `backend/routes/projectRoutes.js`.
    *   **Issue CRUD:** Implemented `POST /api/issues`, `GET /api/projects/:projectId/issues`, `PUT /api/issues/:id/status`, `PUT /api/issues/:id/assignee`, `GET /api/issues/:id`, `DELETE /api/issues/:id` in `backend/controller/issueController.js` and `backend/routes/issueRoutes.js`.
    *   **AI Task Creation:** Implemented `POST /api/issues/ai-create` in `backend/controller/issueController.js` and `backend/routes/issueRoutes.js` (with mocked Gemini API interaction).
    *   **AI Sub-Task Generation:** Implemented `POST /api/issues/:id/generate-subtasks` in `backend/controller/issueController.js` and `backend/routes/issueRoutes.js` (with mocked Gemini API interaction).
    *   **Burndown Chart Data:** Implemented `GET /api/reports/burndown/:projectId/:startDate/:endDate` in `backend/controller/reportController.js` and `backend/routes/reportRoutes.js`.
    *   **AI Predictive Insights:** Implemented `GET /api/insights` in `backend/controller/insightController.js` and `backend/routes/insightRoutes.js`.
*   **Frontend Components & Integration:**
    *   **`ProjectList.jsx`:** Created `frontend/src/pages/Admin/ProjectList.jsx` to display projects and navigate to `CreateProject.jsx` and `ProjectDetails.jsx`.
    *   **`CreateProject.jsx`:** Created `frontend/src/pages/Admin/CreateProject.jsx` with a form for project creation (name, description, members).
        *   Initially used a multi-select dropdown for members, then updated to individual checkboxes with a "Select All" option.
        *   CSS for the form was refactored for better layout and consistency.
    *   **`ProjectDetails.jsx`:** Created `frontend/src/pages/Admin/ProjectDetails.jsx` to display project details, with buttons for "Create Issue", "Edit Project" (placeholder), "Delete Project", and "View Burndown Chart".
    *   **`KanbanBoard.jsx`:** Created `frontend/src/pages/Admin/KanbanBoard.jsx` to display issues by status.
        *   Removed commented-out `react-beautiful-dnd` code.
        *   Improved column styling (`h-full`, `overflow-y-auto`, `max-h-[calc(100vh-200px)]`).
        *   Added hover effect to `IssueCard`.
        *   Made `IssueCard` clickable to navigate to `IssueDetails.jsx`.
    *   **`CreateIssue.jsx`:** Created `frontend/src/pages/Admin/CreateIssue.jsx` with a form for issue creation (title, description, type, status, priority, assignee, due date, parent issue).
    *   **`IssueDetails.jsx`:** Created `frontend/src/pages/Admin/IssueDetails.jsx` to display issue details, with buttons for "Generate Sub-tasks", "Edit Issue" (placeholder), and "Delete Issue".
    *   **`AITaskInput.jsx`:** Created `frontend/src/components/AITaskInput.jsx` for AI-assisted task creation. Integrated into `ProjectDetails.jsx`.
    *   **`BurndownChartPage.jsx`:** Created `frontend/src/pages/Admin/BurndownChartPage.jsx` to display burndown charts, with filters for project, start date, and end date. Uses `recharts`.
    *   **`Dashboard.jsx` (Admin):** Integrated AI Predictive Insights display.
*   **API Path Updates:**
    *   `frontend/src/utils/apiPaths.js` updated with new paths for Projects, Issues (including AI-related), and Reports.
*   **Routing Updates:**
    *   `frontend/src/App.jsx` updated with new routes for ProjectList, CreateProject, ProjectDetails, KanbanBoard, CreateIssue, IssueDetails, and BurndownChartPage.

**7. UI/UX Enhancements & Bug Fixes:**
*   **SideMenu Scrollability:**
    *   Removed `overflow-hidden` from the main container `div` in `frontend/src/components/layouts/SideMenu.jsx`.
    *   Added `max-h-[calc(100vh-150px)]` and `pb-4` to the "Menu Items" `div` in `frontend/src/components/layouts/SideMenu.jsx` to ensure scrollability and proper bottom padding.
*   **Navbar Tooltips:** Added `title` attributes to icon buttons in `frontend/src/components/layouts/Navbar.jsx` to display functionality names on hover.
*   **`insightsData.map` Error Fix:** Added `Array.isArray(insightsData)` check before calling `.map()` on `insightsData` in `frontend/src/pages/Admin/Dashboard.jsx` to prevent "TypeError: insightsData.map is not a function". Removed debugging `console.log` from `useFetchData.js`.

**8. Tool Limitations Encountered:**

This has blocked installation of necessary packages (e.g., `react-beautiful-dnd`, `@google/generative-ai`) and effective debugging/communication.
